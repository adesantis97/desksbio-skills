# desks.bio skills

The free desks.bio skills for biologists live in **[adesantis97/desks](https://github.com/adesantis97/desks)**:

- `colony-count`: colony formation assays from photos of the dishes
- `invasion-count`: Transwell invasion/migration from microscope fields

Install in Claude Code:

```
/plugin marketplace add adesantis97/desks
/plugin install bench-assays@desks
```

Each skill is a plain `SKILL.md` folder under `plugins/bench-assays/skills/`, usable by any agent that reads skills.
