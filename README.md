# desks.bio skills

Open-source [Claude Code](https://claude.com/claude-code) skills for biologists, built and used daily at [desks.bio](https://desks.bio).

Each folder is one skill: a `SKILL.md` plus any helper scripts it needs.

## Install a skill

```bash
git clone https://github.com/adesantis97/desksbio-skills.git
cp -r desksbio-skills/<skill-name> ~/.claude/skills/
```

Then call it in Claude Code with `/<skill-name>`.
